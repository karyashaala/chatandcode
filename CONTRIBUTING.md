# Contributing

Pull requests are open to collaborators only for now.

You can still help by reporting bugs, sharing ideas, and asking questions.

## Bug reports

Report bugs in [GitHub Issues](https://github.com/karyashaala/chatandcode/issues).
Search existing issues before opening a new report.

Include:

- ChatAndCode version.
- Operating system and version.
- Surface: web, desktop, or mobile.
- Provider, such as Codex or Claude.
- Steps to reproduce, what you expected, and what happened.

## Ideas

Share ideas in [GitHub Issues](https://github.com/karyashaala/chatandcode/issues).
Describe the problem you want to solve and how it affects your work.

## Questions

Ask questions in [Discord](https://discord.gg/4DfrnRHSmh).

## Security

Report security vulnerabilities only by email to
[chatandcode@gmail.com](mailto:chatandcode@gmail.com), never in Issues or Discord.
See the [security policy](.github/SECURITY.md) for scope and reporting details.

## Developer setup

See the [development runbook](docs/operations/development.md#first-checkout) for the initial checkout,
development commands, tests, and platform-specific desktop packaging prerequisites.

Follow the [documentation rules](AGENTS.md#documentation).
